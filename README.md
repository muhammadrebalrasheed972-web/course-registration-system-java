# 🎓 Course Registration System (Java)

## 📌 Description
This is a console-based Course Registration System developed in Java.  
It allows managing students, courses, and registrations using Object-Oriented Programming (OOP) concepts.

---

## 🚀 Features
- Add new students
- Add new courses
- Register students in courses
- Search course registrations
- Simple menu-driven interface

---

## 🛠️ Technologies Used
- Java
- OOP (Classes, Objects, Methods)
- ArrayLists (for storing data)

---

## ▶️ How to Run
1. Open the project in any Java IDE (like IntelliJ or Eclipse)
2. Run the `Main.java` file
3. Follow the menu options in output console

---

## 📚 Concepts Practiced
- Object-Oriented Programming
- Data management
- User input handling (Scanner)
- Basic system design
